# ВАЖНО: Как обновить расширение

## Проблема
Браузер загружает расширение в память при установке. Изменения в файлах НЕ применяются автоматически.

## Решение: Перезагрузка расширения

### Chrome / Edge / Яндекс
1. Открой `chrome://extensions`
2. Найди "Faceit Match Helper for Bot"
3. Нажми **кнопку "Обновить" (круговая стрелка)** под расширением
4. ИЛИ: удали расширение и заново "Загрузить распакованное"

### Firefox
1. Открой `about:debugging#/runtime/this-firefox`
2. Найди "Faceit Match Helper for Bot"  
3. Нажми **"Перезагрузить"** (Reload)
4. ИЛИ: удали и заново "Load Temporary Add-on"

## После перезагрузки
1. Закрой **ВСЕ вкладки** faceit.com
2. Открой faceit.com заново
3. Открой консоль (F12)
4. Должно появиться:
   ```
   [FaceitBot] inject loaded (MAIN world)
   ```

## Проверка версии
В `chrome://extensions` или `about:debugging` должно быть:
- **Version: 1.2** (не 1.1!)

## Если не помогает
1. Полностью удали расширение
2. Перезапусти браузер
3. Заново установи расширение из папки
4. Убедись что выбрал правильную папку `extension/` (там manifest.json)

## Debug
Если в консоли НЕТ `[FaceitBot] inject loaded`:
1. Проверь что расширение включено (toggle вкл)
2. Перезагрузи страницу faceit.com (Ctrl+R)
3. Проверь ошибки в фоновом скрипте:
   - Chrome: `chrome://extensions` → "Проверить представления" → background.html
   - Firefox: `about:debugging` → "Инспектировать"
