## Перед тестированием

1. **Обнови Worker на Cloudflare**
   - Скопируй `cloudflare_worker.js`
   - Задеплой на https://polished-mouse-4c9d.mishashlikov216.workers.dev

2. **Перезапусти бота**
   ```bash
   python bot.py
   ```

3. **Переустанови расширение в браузере**
   - Удали старую версию
   - Загрузи новую (v1.2)

## Тестирование расширения

### Шаг 1: Привязка токена
1. В Telegram боте: `/facelogin`
2. Скопируй токен (он теперь НЕ меняется при повторном вызове)
3. Кликни по иконке расширения → вставь токен → "Сохранить"
4. **Ожидаемое**: 
   - Показывается твой Faceit аватар
   - Faceit никнейм
   - Telegram username
   - Статус: "✓ Активно — расширение работает"
   - Бот пришлёт подтверждение в Telegram

### Шаг 2: Проверка логов
1. Открой https://www.faceit.com залогиненным
2. Открой консоль (F12)
3. **Ожидаемое в консоли**:
   ```
   [FaceitBot] inject loaded (MAIN world)
   [FaceitBot] REQ: https://api.faceit.com/...
   ```

### Шаг 3: Проверка статистики
1. Открой любой профиль игрока на faceit.com
2. **Ожидаемое**:
   - Floating-кнопка "Бот" справа внизу
   - Блок "Расширенная статистика (из бота)" вверху страницы
   - В консоли: `[FaceitBot] STATS найдены: {...}`

### Шаг 4: Проверка матча
1. Найди/начни матч на faceit.com
2. **Ожидаемое**:
   - В консоли: `[FaceitBot] MATCH найден: ...`
   - Бот пришлёт "ПРЕДМАТЧ-АНАЛИЗ" в Telegram (~30 секунд задержка)

## Если не работает

### Расширение не загружается
- **Firefox**: проверь что загружаешь как Temporary Add-on
- **Chrome/Edge**: включи "Режим разработчика"
- Проверь что выбрал правильную папку (там должен быть manifest.json)

### В консоли нет "[FaceitBot] inject loaded"
1. Перезагрузи страницу faceit.com
2. Проверь что расширение включено
3. Проверь что нет ошибок в консоли (красные строки)

### Токен не работает ("токен не найден")
1. Убедись что бот запущен
2. Заново вызови `/facelogin` в боте
3. Скопируй НОВЫЙ токен (не старый из истории)
4. Проверь что Worker задеплоен

### Матч не приходит в бота
1. Проверь что токен привязан (options → "✓ Активно")
2. Проверь в консоли что матч перехвачен: `[FaceitBot] MATCH найден`
3. Подожди 30 секунд (бот поллит Worker раз в 30с)
4. Проверь логи бота: `Worker KV: user ... synced`
